# VŨ VÉ XE - Website đặt vé

Phiên bản này có tính năng:
- Chọn tuyến từ trang chủ.
- Chuyển sang trang danh sách nhà xe theo tuyến.
- Bấm ĐẶT VÉ NHÀ XE NÀY để mở form.
- Nhập ngày đi, giờ, số khách, họ tên, số điện thoại.
- Gửi yêu cầu đặt vé sang Zalo 0386003098.

Đây là website tĩnh, chưa có hệ thống giữ chỗ/thanh toán tự động. Việc xác nhận chỗ và giá vẫn do Vũ Vé Xe kiểm tra qua Zalo.
