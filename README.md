# VŨ VÉ XE - Website bản 0 đồng

## Cách sử dụng
1. Giải nén thư mục.
2. Upload toàn bộ file lên GitHub Repository.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, thư mục `/ (root)` rồi Save.
6. Chờ GitHub Pages tạo website.

## File chính
- `index.html`: giao diện website.
- `style.css`: giao diện và responsive.
- `script.js`: chức năng chọn tuyến, chọn loại xe và tạo tin nhắn đặt xe.
